# sandbox — 각자 개인 작업 공간

**팀원 1명 = 폴더 1개.** 처음 오면 **자기 GitHub 계정 이름(git 아이디)**으로 폴더를 만들면 된다 (예: `sandbox/NaHoYeol/`). AI가 아이디를 알아서 확인해준다 (AGENTS.md §9-3).

**왜 만들었나**: 여러 명이 같은 파일을 만지면 충돌이 나고, 개인 실험이 팀 공용 폴더에 섞이면 뭐가 진짜인지 헷갈린다. "자기 폴더 안은 전부 자유, 밖은 규칙대로"로 나누면 두 문제가 동시에 사라진다.

## 규칙

- **자기 폴더 안에서는 전부 자유.** 실험 코드, 노트북, 개인 중간 결과물(예: `sandbox/NaHoYeol/result/`), 메모 — 뭐든 OK. 리뷰 없이 main에 바로 푸쉬해도 된다.
- **남의 폴더는 읽기만.** 수정하지 않는다.
- 개인 산출물을 `data/result/`에 바로 넣지 않는다 — 거기는 **통합 코드(`code/`)가 만든 팀 공용·최종 결과물 전용**이다.
- 승격 흐름: `sandbox/`에서 실험 → 검증되면 `code/`로 PR → 통합 코드가 만든 결과물이 `data/result/`로.
- 폴더·파일 이름은 영문(ASCII)으로, 10MB 초과 파일은 커밋 금지 (data 규칙과 동일).
