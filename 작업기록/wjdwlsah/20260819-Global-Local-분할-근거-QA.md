사용자가 순서대로 확인 질문을 던짐:
1. 6개 직군 KECO 매핑 기준이 뭔지
2. Local 6개를 합치면 왜 4,603개뿐인지, 그 근거가 뭔지
3. 어느 프로토콜 조항이 "희망직업 응답 있는 행만 Local에 쓴다"를 명시하는지
4. Global train 5,737명·test 1,406명이 "전체 데이터셋"이 맞는지 (→ 아님, 사람 수)
5. Global 총 행 개수가 정말 7,143개인지 (→ 아님, 14,906행. 7,143은 고유 사람 수)
6. 위 내용을 행 개수 기준으로 다시 표로 정리해달라
7. Global test가 Local train에 섞이는 경우가 정말 전혀 없는지 (직군별로) 재확인
8. (그 결과) 두 PR을 하나로 합칠 수 있는지, 어떤 방식으로
9. 이 QA 내용을 표와 함께 작업기록에 커밋·푸시해서 남겨달라는 지시(이 문서)

## AI가 한 일 / 검증 결과

### 1) KECO 6개 직군 매핑 기준
- 원자료 문항 `c773z`(현재 취업·이직 준비 중 희망직업)/`a244z`(졸업 전후 장래 희망직업)이 이미 KECO 대분류 코드로 응답됨. 특수코드(`9999997`/`9999998`/`9999999`)는 `code/config/yp2021_missing_rules.json:57-64`에서 `Missing` 처리.
- KECO 대분류(0~9) → 6개 직군 매핑은 **계산이 아니라 팀이 정한 고정표**(`code/config/keco_mapping.csv`, 정본):

| KECO 대분류 | 직군 |
|---|---|
| 0 | 경영·사무·금융 |
| 1, 7, 8 | 연구·공학·산업기술 |
| 2 | 교육·법률·사회·공공 |
| 3 | 보건·의료 |
| 4 | 예술·디자인·방송·스포츠 |
| 5, 6, 9 | 서비스·영업·판매·운송 |

- 근거 출처: `회의기록/안건.md`상 2026-08-13 Kim ByngKyu가 확정 필요 항목으로 올렸고 2026-08-14 프로토콜 v1.2 반영 시 해결 처리. 왜 1·7·8을, 5·6·9를 하나로 묶었는지의 실제 판단 근거(유사성 기준)는 회의록·프로토콜 문서에 별도로 남아있지 않음 — 필요하면 추가로 찾아야 함.

### 2)~3) 4,603행의 근거 — raw 데이터로 단계별 재현

| 단계 | 내용 | 행/사람 수 |
|---|---|---:|
| 원본 | Global person_period 전체 | 14,906행 |
| ① `c773z`/`a244z` 실제 응답 수집 | graduation_future 4,497건 + current_preparation 3,146건 | 7,643건, 고유 5,087명 |
| ② baseline_year 이하 응답만 매칭 | person_period 행 중 매칭된 것 | **4,603행** |
| ③ 최신 응답 1개 선택 | 그대로 유지 | 4,603행 |
| ④ KECO 매핑 join | 매핑 실패 0건 | **4,603행 (최종)** |

- 근거 조항: `plan/details/11-YP2021-공통-전처리-모델링-프로토콜.md` **§12, 247번째 줄** — "Local Dataset은 Global Person-Period의 부분집합이다. Global Person-Period 중 baseline year까지 유효한 희망직업이 존재하는 행만 Local 후보가 된다." §12.1(249-255줄)·§12.2(257-265줄)가 시간 기준·최신 응답 선택 규칙을 구체화. 코드로는 `code/pipeline/build_local.py:37`(baseline_year 이하 필터), `:45`(`job_group.notna()` 필터)가 이 규칙을 그대로 구현.
- 나머지 10,303행이 응답이 없는 이유: 결측이 아니라 **애초에 질문 대상이 아니었던 사람들**. 96.5%(9,946행)가 `nonemployment_type=economically_inactive`(비경제활동인구), 92%가 최근 구직활동/취업준비 없음 — 구직·취업준비를 안 하니 희망직업을 물을 논리적 근거 자체가 없는 구조적 비해당.

### 4)~5) "7,143"은 행 개수가 아니라 고유 사람(SAMPID) 수
- Global 원자료 응답자(패널 전체, 4개 차수 공통): **12,213명**
- §2 분석대상 필터(기준연도 미취업 `ECOACT∈{2,3}` 등) 통과 후 고유 SAMPID: **7,143명** (원자료의 58.5%)
- 그 사람들의 Person-Period **총 행 수는 14,906행**(사람마다 최대 3개 baseline_year 행) — 이게 Global Model이 실제로 학습·평가에 쓰는 행 개수.
- train 5,737명+test 1,406명=7,143명(사람 기준 100%), train 12,012행+test 2,894행=14,906행(행 기준 100%) — 빠진 인원·행 없음.
