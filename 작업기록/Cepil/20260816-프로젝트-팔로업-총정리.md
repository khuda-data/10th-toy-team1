7. 전체 데이터 전처리 파이프라인 흐름도 검증

## 요약 내용

### 1. 프로젝트 흐름 및 현황
- **주제**: 청년의 취업준비 특성 기반 차년도 취업 여부 예측 (이진 분류)
- **데이터**: 청년패널2021(YP2021) 1~4차 데이터
- **진행 상황**: 기획서 제출 및 파이프라인 뼈대(v1.3) 구축 완료. 분석 대상을 '미취업자 전체'로 확장하고 Global(14,906행) 및 Local(4,603행) 데이터셋 도출 완료.
- **남은 과제**: 전공 대계열, 자격증, 일경험 등 약 31개 Feature의 원변수 매핑 로직 구현 및 설문 문항 확정.

### 2. 주요 팀원 작업 내역
- **김병규 (공통 파이프라인)**: 데이터 풀링 구조, 특수 결측치 규칙, 파이프라인 뼈대 코드(`code/pipeline`, `preprocess` 등) 작성 및 산출물 생성.
- **최승호 (Global 전처리)**: 데이터 정합성 검증, 연도별 취업 전환율 분석, 연도별 특수성 통제를 위한 `baseline_year` 원-핫 인코딩 고정효과 채택.
- **정진모 (Local 전처리)**: 업무 지침과 실제 코드 간 Gap 분석(누락된 31개 Feature 식별), 과대표집 문제 분석, 향후 개발 To-Do 리스트 정리.

### 3. 원본 데이터 관리 규칙
- **데이터 위치**: 10MB 초과 파일은 Git에 올리지 않으므로, `Dataset&manual` 패키지를 팀원 각자가 로컬에 보관.
- **실행 방식**: 파이프라인 코드 실행 시 원본 압축파일(`YP2021_EXCEL_0227 (1).zip`)의 로컬 절대 경로를 전달해 임시 폴더에서 읽도록 처리.
- **공식 링크**: `plan/details/10-YP2021-직군별-취업예측-계획.md`에 기재된 한국고용정보원 다운로드, 유저가이드, 코드북 링크 확인.

### 4. 피처 엔지니어링 및 엑셀 데이터 혼선 해소
- **피처 엔지니어링의 의미**: 원본 데이터에 정보가 없는 것이 아니라, 복잡한 설문 문항 코드(`y21c602` 등)를 우리가 사용할 42개 Feature 형태로 묶고, 과거 이력을 누적(예: 자격증 수 합산)하며 중복을 제거하는 매핑 코드를 작성해야 한다는 뜻.
- **엑셀 혼선 주의**: 복잡한 문항 코드가 보이지 않는다면 잘못된 파일(직업력 자료 또는 매핑표)을 보고 있을 확률이 높음. 실제 문항 코드는 압축을 푼 `일반조사 자료 (YP2021_w04.xlsx)`에 들어 있음.

### 5. 전처리 파이프라인 흐름도 검증
사용자가 제시한 흐름도는 현재 프로젝트의 v1.3 프로토콜 및 GitHub 파이프라인 구현체와 **완벽하게 일치함**.
- 연도별 표준화 → 미취업자 분리 → Target 생성 → baseline까지 Feature 생성 → 결측치 처리 → **Global Dataset** → 최신 유효 희망직업 조회 → KECO 6개 직군 매핑 → **Local Dataset** 산출 순서.
