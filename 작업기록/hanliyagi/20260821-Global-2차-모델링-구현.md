# 2026-08-21 Global 2차 모델링 구현

- 도구/모델: Codex / GPT-5
- 브랜치: feat/hanliyagi-global-model-prep

## 지침 (내가 시킨 것)

- "Global Model의 2차 모델링을 진행해줘"라고 요청했다.
- 첨부한 `YP2021_Stage2_42features_최종_선정표.xlsx`의 사람이 결정한 사용 Feature만 쓰고, AI가 임의로 Feature를 추가하거나 제거하지 말라고 했다.
- Logistic Regression과 XGBoost를 선택 Feature 기준으로 처음부터 다시 튜닝하고, Stage 1과 같은 Global split·Train-only·SAMPID 5-fold·random_state=42·F1·threshold=0.5·전처리 원칙·탐색 범위를 유지하라고 했다.
- Test Dataset은 사용하지 않고, `notebooks/global/03_second_model.ipynb`에서 LR/XGB 1차·2차의 수치·지정 시각화·OOF 혼동행렬을 비교하되 최종 모델 선택이나 결과 해석은 하지 말라고 했다.

## AI가 한 일

- 첨부 Excel의 `최종요약` 및 `42개_Feature_최종판단` 시트에서 사용으로 표시된 25개 Feature를 읽었다. 목록을 `code/config/features.yaml`의 `feature_sets.global_stage2_selected_25`에 같은 순서로 등록했다.
- `named_feature_set()`과 `select_bundle_features()`를 추가해 선택 목록을 설정에서 검증하고, Train bundle의 y·SAMPID·split을 바꾸지 않은 채 Feature 열만 선택하도록 했다.
- 기존 `run_first_stage_modeling()`의 공통 GridSearchCV·OOF 로직을 `run_global_cv_modeling()`으로 분리했다. Stage 1 42개 검증은 유지하고, Stage 3은 공통 함수를 호출해 새 25개 Feature로 LR/XGB를 재튜닝한다.
- Stage 1과 Stage 3 결과를 재사용할 수 있도록 OOF·summary·best parameter·fold F1 artifact 저장을 보완했다. Stage 3 결과는 `data/result/baseline_42features/modeling/stage_3/`에 저장한다.
- Stage 3 Notebook은 저장된 Stage 1 summary·OOF·fold F1을 불러 네 후보(LR/XGB × 1차/2차)의 CV/OOF 비교표, CV F1·ΔF1·표준편차·Precision·Recall·fold F1·OOF 혼동행렬을 표시한다.

## 검증 (내가 직접 확인한 것)

- 실제 저장 Global Train의 앞 400 SAMPID/886 Person-Period만 이용한 축소 탐색으로 사람 확정 25개 Feature가 정확히 선택됨을 확인했다.
- 축소 탐색 설정에서 LR·XGBoost 각각의 GridSearchCV와 5-fold OOF 886행을 생성했다. XGBoost는 `train_negative_positive_ratio` marker를 그대로 사용했다. Test Dataset은 만들거나 읽지 않았다.
- `01_first_model.ipynb`, `02_feature_selection.ipynb`, `03_second_model.ipynb`의 JSON과 모든 Python 셀 컴파일을 확인했다.

## 남은 것 / 사람 판단 필요
