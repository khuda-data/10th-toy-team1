# design — 디자인 토큰 (수정 금지)

**무엇**: 우리 팀의 모든 시각 산출물이 따르는 디자인 규격서 2개.

| 파일 | 적용 대상 |
|---|---|
| `DESIGN-apple.md` | **앱·웹 화면·PPT·대시보드·포스터 등 눈에 보이는 것 전부** (기본값) |
| `DESIGN-notion.md` | 논문 한국어 해설 HTML **전용** (유일한 예외) |

**왜 만들었나**: 각자 AI에게 "앱 만들어줘"라고 하면 제각각의 디자인이 나온다. 디자인 감각이 없어도, 서로 상의하지 않아도 결과물이 한 팀 것처럼 보이게 하려고 규격을 하나로 고정했다. AI가 이 토큰(색·글꼴·간격 값)만 쓰도록 AGENTS.md §5에 지시돼 있다.

**규칙**: 두 파일 모두 **수정 금지**. 필요한 토큰이 없으면 임의로 추가하지 말고 팀장에게 요청.
