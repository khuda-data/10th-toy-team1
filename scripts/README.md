# scripts — 유틸 스크립트와 git 훅

**무엇**: 프로젝트 산출물은 아니지만 작업을 돕는 도구들.

| 폴더 | 무엇 | 비고 |
|---|---|---|
| `githooks/` | git 훅 — `pre-commit`이 작업기록 없는 커밋을 차단 | 활성화: `git config core.hooksPath scripts/githooks` (온보딩.md 3단계) |
| `fig_extract/` | 논문 PDF에서 그림·표를 잘라내는 스크립트 + 중간 산출 이미지 | 재생성 가능 — 지워져도 다시 만들 수 있음 |

**왜 만들었나**: 도구 스크립트가 code/(팀 공동 결과물)나 문서 폴더에 섞이면 "이게 프로젝트 코드인가 도구인가"를 매번 구분해야 한다. 도구는 여기에만 모은다.

**규칙**: 새 유틸 스크립트를 만들면 여기 하위 폴더로 + 이 표에 한 줄 추가.
