# 불확실성 인내력 부족 → 사회비교경향성 → 취업불안 (2025)

**무엇**: 미취업 대학생에게서 **"불확실성을 못 견디는 성향 → 남과 비교함 → 취업불안"** 경로를 검증한 국내 실증 연구.

**왜 받았나**: 우리 연구의 문제 정의("자기 위치를 모르면 남과 비교하게 되고 그게 불안이 된다")를 국내 데이터로 뒷받침하는 논문이 필요했다. `plan/details/07-연구설계-선행연구맵.md` §2 원인 분석의 핵심 근거다.

## 핵심 내용

**만 20~32세 미취업 대학생 199명** 온라인 자기보고 설문. SPSS 23.0 + PROCESS Macro 4.2.

1. 불확실성 인내력 부족·사회비교경향성·취업불안은 서로 유의한 **정적 상관**. 심리적 유연성은 세 변인 모두와 **부적 상관**.
2. 불확실성 인내력 부족 → 취업불안 관계에서 **사회비교경향성의 매개효과 확인**.
3. **사회비교경향성 → 심리적 유연성의 순차 매개효과**도 검증됨.

취업불안의 정의를 조규판(2008)에서 가져다 쓴다 — 같은 폴더 계열의 [`JobAnxietyScale_Cho_2008`](../JobAnxietyScale_Cho_2008/) 참조.
