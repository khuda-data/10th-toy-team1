# 한국 대학생 취업 스트레스 척도 개발 및 타당화 (2023)

**무엇**: 국내 대학생의 취업 스트레스를 재는 척도를 새로 개발·타당화한 논문. 하위요인에 **'스펙 관련 스트레스'**가 있어 우리 주제(스펙↔공고 매칭)와 가장 가깝다.

**왜 받았나**: `plan/details/07-연구설계-선행연구맵.md`의 실험 설계에서 사전·사후에 쓸 척도 후보를 고르기 위해. '스펙 관련 스트레스' 6문항이 "내 스펙이 부족한지 모르겠다"는 상태와 얼마나 겹치는지 확인이 필요했다.

**스펙 관련 스트레스 6문항** (우리 주제와 직결):

1. 학점이 좋지 않으면, 취업하는 데 불리할 것 같아 걱정이다.
2. 취업을 위해서 높은 학점이 유리할 것 같아 부담스럽다.
3. 최소 한 가지 외국어는 구사해야 취업할 것 같아 스트레스를 받는다.
4. 취업을 위해 외국어 공부를 하는데, 실력이 늘지 않아 답답하다.
5. 혼자서 취업에 필요한 자격증을 준비하는 게 벅차다.
6. 취업하기 위해 대외활동을 해야 할 것만 같은 압박감이 든다.

22문항 전체와 요인부하량은 `kim2023.md`의 탐색적 요인분석 표 참조. 우리 실험에서의 활용 판단은 `plan/details/07-연구설계-선행연구맵.md` §5-1·부록 A-4.
