# 스펙경쟁 사회에서 자기계발 동기·강박이 취업준비생 심리에 미치는 영향 (2020)

**무엇**: '스펙 경쟁'이라는 한국 특유의 상황을 산업·조직심리 관점에서 다룬 논문. 자기계발 **동기**와 자기계발 **강박**을 구분해, 각각이 취업준비생의 심리 상태에 어떤 영향을 주는지 검증했다.

**왜 받았나**: 우리가 다루는 '스펙'을 정면으로 다룬 국내 논문 중 도메인이 가장 가깝다. `plan/details/07-연구설계-선행연구맵.md` §1 배경 또는 §2 원인 분석에 배치할 후보다.
