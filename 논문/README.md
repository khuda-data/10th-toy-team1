# 논문 — 선행연구 보관소

**무엇**: 프로젝트를 위해 읽은 논문들. **논문 1편 = 전용 폴더 1개** 원칙으로, 폴더마다 아래가 들어간다:

```
논문/<논문 코드명>/           ← 예: EyesOnTheStreet_Quito_2025
  ├── <원본>.pdf             ← 논문 원본 (레포에서 PDF 커밋이 허용되는 유일한 곳)
  ├── <원본>.md              ← 원본의 md 변환본 (GitHub에서 바로 읽는 용도)
  ├── [해설] <원본>.html/.md ← 한국어 해설 (전문 번역 + 주석)
  └── assets/                ← md 변환 시 추출된 그림·표 이미지
```

**왜 만들었나**: 논문은 프로젝트 결정의 근거인데, 원본·번역·해설이 흩어지면 "그 근거가 어느 논문 어디였지?"를 못 찾게 된다. 한 폴더에 원본과 해설을 묶어 근거 추적이 가능하게 했다.

**규칙**: 원본 PDF는 삭제·수정 금지. 어떤 논문을 읽었는지 목록은 `plan/details/03-논문인덱스.md`, 해설 만드는 절차는 `plan/details/02-한국어해설-작성지침.md`.

**검색은 루트 `검색기록/`부터**: 새 논문을 찾을 때는 어떻게 검색했고 왜 채택/제외했는지가 [`../검색기록/`](../검색기록/README.md)에 자동으로 남는다 (AI가 작성). 검색 전 중복 확인도 그 규칙에 포함.
