# data/raw — 원본 데이터 (수정 금지)

YP2021 원자료는 용량·라이선스 때문에 Git에 넣지 않는다. 팀원이 공식 경로에서 받은 `YP2021_EXCEL_*.zip`을 로컬에 보관하고, 실행할 때 절대경로를 `--raw-zip`으로 전달한다. 통합 파이프라인은 원본 zip을 수정하지 않고 임시 폴더에서 읽는다.

## 현재 공통 입력

| 파일 | 출처 | 사용 방식 | Git 상태 |
|---|---|---|---|
| `YP2021_EXCEL_0227 (1).zip` | 팀 공유 `Dataset&manual` 패키지 · 한국고용정보원 YP2021 1~4차 Excel | `python -m code.pipeline.run_pipeline --raw-zip <경로>` | 미커밋 |
| `청년패널2021 1-4차 조사 매핑표_0227 (1).xlsx` | 같은 패키지 | 원변수명 대조 | 미커밋 |
| `청년패널2021 1-4차 조사 코드북_0227 (1).xlsx` | 같은 패키지 | 특수결측·설문분기 대조 | 미커밋 |

원자료를 새로 받거나 다른 버전으로 바꾸면, 해당 파일의 출처·날짜·버전을 `../README.md` 표에 추가하고 `code/config` 및 인터페이스와 맞는지 확인한다.
