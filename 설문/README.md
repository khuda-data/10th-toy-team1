## 왜 만들었나

YP2021 데이터로 만드는 예측 모델과 별개로, **우리 프로그램이 실제로 사람에게 도움이 됐는지**를 사전-사후 설문으로 확인하려는 계획이 있다 (`plan/details/07-연구설계-선행연구맵.md`). 그 계획을 실제 배포 가능한 설문지 형태로 옮겨두는 곳이다.

설문지를 문서 여기저기에 흩어 두면 "어느 버전이 최종인지"를 아무도 모르게 된다. 그래서 한 폴더에 모은다.

## 규칙

1. **배포 전에 `⬜ 미검토` 표시를 확인한다.** 설문 문항 선택·대상자 설계는 대원칙상 사람이 판단해야 하는 영역이다 (`AGENTS.md` ⭐). AI가 초안을 쓴 대목에는 `〔AI 제안 · 사람 검토 필요〕`가 붙어 있고, **그 표시가 남은 채로 배포하면 안 된다.**
2. **척도 문항은 원문 그대로 쓴다.** 표현을 다듬거나 순서를 바꾸면 원 논문의 신뢰도·타당도를 빌려올 수 없게 된다. 고쳐야 할 이유가 생기면 팀 회의 안건으로 올린다.
3. **사전과 사후 설문의 문항은 완전히 같아야 한다.** 문항이 달라지면 전후 비교가 성립하지 않는다.
4. **응답 원자료는 이 폴더에 두지 않는다.** 개인정보가 들어가므로 레포에 올리지 않는다 (`.gitignore` 확인 후 별도 보관).
5. 새 설문지를 만들면 파일명에 날짜를 넣고, 옛 버전을 지우지 말고 남긴다 (`-YYYYMMDD`).
6. **hwp는 레포에 올리지 않는다** (`AGENTS.md` §4 — 문서는 md로 커밋). md가 정본이고 hwp는 그것을 IRB 양식에 부은 인쇄용 사본이다. **내용을 고칠 땐 md부터 고치고 hwp에 반영한다.** hwp만 고치면 왜 그렇게 됐는지가 팀에게 안 보인다.
