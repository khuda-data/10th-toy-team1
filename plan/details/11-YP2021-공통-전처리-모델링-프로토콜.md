# YP2021 공통 전처리·모델링 프로토콜 v1.2

> 이 문서는 사용자가 제공한 “YP2021 공통 전처리·모델링 프로토콜 v1.2”를 팀 저장소에서 실행 기준으로 보관한 것이다. 코드 구현은 이 기준을 바꾸지 않으며, 상세 파일·함수 계약은 [`06-인터페이스.md`](06-인터페이스.md)를 따른다.

## 고정 연구 기준

- 분석 단위는 `SAMPID × baseline_year` Person-Period이고 전환은 2021→2022, 2022→2023, 2023→2024다.
- 기준연도와 다음연도에 모두 응답했고, 기준연도 `ECOACT`가 실업자 또는 비경제활동인구이며, `y**c602=1` 또는 `y**c635=1`인 사람만 포함한다.
- Target `employment_transition`은 다음연도 `ECOACT=1`이면 1, 실업/비경제활동이면 0이다. 실제 취업직군과 희망직군의 일치는 Target에 넣지 않는다.
- 모든 Feature는 baseline year까지 실제로 관측된 정보만 쓴다. 다음연도 변수, 다음연도 임금·직종·근로형태·구직활동·자격증·훈련 등은 금지한다.
- 상태형 변수는 기준연도 값, 이력형 변수는 기준연도까지 관측된 이력을 누적한다. 동일 이력은 가능한 경우 코드·기간으로 중복 제거한다.
- Local은 기준연도까지의 가장 최근 실제 희망직업을 사용한다. 같은 시점이면 현재 취업·이직 준비 과정 응답을 졸업 전후 장래 희망직업보다 우선한다.
- KECO 대분류는 `code/config/keco_mapping.csv`의 6개 직군으로 변환하며, 팀원은 임의 변경하지 않는다.

## 공통 전처리·분할·모델 기준

- Global/Local은 Feature 목록, Target, 결측·비해당·이상치 처리, 모델 후보, 탐색 범위, 평가 기준을 동일하게 쓴다.
- 실제 결측은 수치형 Train median, 범주형 `Missing`으로 처리한다. 비해당은 논리적 0인 경우만 0, 그 외는 `NotApplicable`이다.
- 무응답·모름·응답거절 특수코드는 변수별 코드북으로 확인해 `NaN`으로 바꾼다.
- 범주형은 One-Hot, Train 빈도 10 미만은 `Other`로 통합한다. `Missing`·`NotApplicable`은 통합하지 않는다.
- Logistic Regression만 `StandardScaler`를 쓰고, 모든 학습형 전처리는 Train에서만 fit한다.
- SAMPID 기준 `StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42)`로 Global Train/Test를 한 번 나누고, Local도 같은 SAMPID split을 쓴다. Train 80%/Test 20%, Test fold=0이다.
- oversampling/undersampling은 기본으로 쓰지 않는다. class weight 관련 값만 공통 탐색 후보에 넣는다.
- 모델 후보는 Logistic Regression, Decision Tree, Random Forest, XGBoost, LightGBM이다. 탐색은 기본 GridSearchCV, 계산량이 과도하면 팀 공통 RandomizedSearchCV 30회로 변경한다.
- 튜닝의 scoring은 F1이며 Test는 선택에 쓰지 않는다. threshold는 0.5로 고정한다.

## 평가·결과 기준

- 주 지표는 Positive class(취업전환=1)의 F1이다. Accuracy, Precision, Recall, ROC-AUC, 혼동행렬을 함께 기록한다.
- Importance는 최종 Test에서 `scoring="f1"`, `n_repeats=20`, `random_state=42`인 원 Feature 단위 Permutation Importance로 통일한다.
- 직군별 비교는 같은 Local Test Sample에서 Global Model과 Local Model을 평가하며, `ΔF1 = Local F1 - Global F1`을 중심으로 기록한다.
- 불확실성은 SAMPID 단위 bootstrap 1,000회 95% CI를 보조로 계산한다.
- 정식 Local 비교의 최소 표본은 Person-Period 150 이상, 고유 SAMPID 100 이상, 각 class 40 이상이다. 100~149행·각 class 30 이상은 탐색적 결과로만 표시한다.

## 팀원 금지사항

- 분석 대상, 비구직자 포함, Target, KECO 매핑, Feature 목록을 개인 판단으로 바꾸지 않는다.
- 미래 정보를 Feature로 쓰지 않는다.
- split을 다시 만들거나 동일 SAMPID를 Train/Test에 나누어 넣지 않는다.
- Local만의 결측 처리·인코딩·Feature·모델 후보·탐색 범위·평가 지표 변경을 하지 않는다.
- Test를 모델 선택에 쓰거나, 표본을 늘리기 위한 synthetic/pseudo-label 데이터를 넣지 않는다.

변경이 필요하면 이유와 전후 기준을 문서화하고 팀 합의 → 이 문서 버전·`code/config` 갱신 → 영향받은 실험 재실행 순서로 진행한다.
