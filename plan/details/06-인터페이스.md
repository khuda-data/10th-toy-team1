# 인터페이스 합의 — 모듈끼리의 약속 장부

> **여기 적힌 약속이 곧 계약이다.** 각자 이 형식대로 만들고, 이 형식대로 받는다. 내부 구현은 자유.
> 바꾸려면: 이 문서를 고치는 PR + 팀 채팅 공유 (`05-협업-통합절차.md` 2단계).
> **AI 규칙**: 공용 코드·데이터 작업 전에 이 문서를 읽고, 여기 적힌 형식대로 구현하라. 필요한 약속이 없으면 임의로 정하지 말고 이 문서에 추가하는 것부터 제안하라.
>
> 아직 코드 착수 전이라 아래는 전부 **예시 행**이다. 착수하면 실제 약속으로 바꾼다.

## API 약속 (웹)

| # | 제공하는 쪽 | 쓰는 쪽 | 주소·형식 | 응답 예시 | 상태 |
|---|---|---|---|---|---|
| 예시 | 백엔드(routing) | 프론트(web) | `GET /route?from=<lng,lat>&to=<lng,lat>` | `{"routes":[{"polyline":"...", "distance_km":3.2}]}` | 초안 |

## 데이터 약속 (분석·모델)

| # | 만드는 쪽 | 쓰는 쪽 | 파일·형식 | 스키마 (이름 : 타입 : 단위) | 상태 |
|---|---|---|---|---|---|
| 예시 | 모델(model) | 백엔드(routing) | `data/result/risk_table.npy` | 도로링크 × 시간대 행렬, float 0~1 | 초안 |
| 예시 | 데이터(preprocess) | 모델(model) | `data/result/links.parquet` | `link_id:str`, `length_m:float`, `cctv_cnt:int` | 초안 |
