# 청년패널2021 직군별 취업 예측 프로젝트 진행 계획

## 0. 프로젝트 방향

이번 프로젝트의 기본 목표는 **2023년까지의 청년 개인 특성 및 취업준비 경험을 이용해 2024년 취업 여부를 예측하고, 희망직군에 따라 취업 예측에 중요한 요소가 실제로 달라지는지 확인하는 것**이다.

이를 위해 두 종류의 모델을 만든다.

- **Global Model**: 직군을 구분하지 않고 전체 청년을 대상으로 취업 여부를 예측
- **Local Model**: 희망직군별로 데이터를 나누어 각 직군에 특화된 취업 여부를 예측

두 모델을 동일한 조건에서 비교하여 다음 질문에 답하는 것이 최종 목적이다.

> **직군을 구분하여 별도의 취업 예측 모델을 만드는 것이 전체 청년을 대상으로 하나의 모델을 만드는 것보다 실제로 더 효과적인가?**

또한 Local Model별 주요 Feature를 비교하여 **희망직군에 따라 취업과 관련성이 높은 특성이 다르게 나타나는지** 확인한다.

---

# 1. 사용할 데이터셋

## 1.1 주 데이터: 청년패널2021

한국고용정보원의 **청년패널2021(YP2021) 1~4차 조사자료**를 프로젝트의 핵심 데이터로 사용한다.

청년패널2021은 2021년 당시 만 19~28세 청년 약 1만 2천 명으로 시작한 패널조사로, 같은 사람을 매년 추적하면서 학교생활, 취업준비, 일자리 경험, 직업훈련, 자격증, 경제활동상태 등을 조사한다.

이번 프로젝트에서는 다음 구조로 사용한다.

| 시점 | 프로젝트에서의 역할 |
|---|---|
| 2021년 1차 | 과거 개인 특성 및 희망직업 정보 보완 |
| 2022년 2차 | 과거 개인 특성 및 희망직업 정보 보완 |
| 2023년 3차 | **취업 예측에 사용할 기준시점의 Feature** |
| 2024년 4차 | **실제 취업 여부 Target** |

4차 조사에는 9,665명이 응답했으며, 공식 기초분석보고서에서도 이 데이터를 이용해 학교생활, 취업·취업준비, 직업훈련·자격증, 경제활동상태 변화 등을 분석하고 있다.

## 1.2 직군 구분 자료: 한국고용직업분류

YP2021에서 희망직업은 한국고용정보원의 **한국고용직업분류(KECO)**를 이용해 분류되어 있다.

따라서 원자료의 숫자 코드를 그대로 분석하지 않고, 실제 직업분류를 확인한 뒤 약 6개의 큰 직군으로 재구성한다.

[한국직업사전·한국고용직업분류 안내](https://www.work.go.kr/consltJobCarpa/srch/jobDic/jobDicIntro.do?pageType=jobDicNotes)

현재 계획하는 6개 직군은 다음과 같다.

| 직군 | 포함할 주요 분야 |
|---|---|
| ① 경영·사무·금융 | 경영, 행정, 사무, 금융, 보험 |
| ② 연구·공학·산업기술 | IT, 연구, 공학, 건설, 생산·기술 |
| ③ 교육·법률·사회·공공 | 교육, 법률, 사회복지, 경찰·소방, 공공분야 |
| ④ 보건·의료 | 의료, 간호, 보건 관련 직업 |
| ⑤ 예술·디자인·방송·스포츠 | 문화, 예술, 디자인, 방송, 스포츠 |
| ⑥ 서비스·영업·판매·운송 | 서비스, 영업, 판매, 음식·숙박, 운송 등 |

**정확히 어떤 KECO 직업을 어느 그룹에 넣을지는 전처리 전에 공통 매핑표를 만들어 팀 전체가 동일하게 사용한다.**

## 1.3 보조 데이터: 경제활동인구조사 청년층 부가조사

모델 학습에는 YP2021만 사용하고, **우리 결과가 최근 국내 청년 고용상황과 어느 정도 일치하는지 설명하는 용도**로 경제활동인구조사 청년층 부가조사를 사용한다.

2025년 자료에는 청년 고용률뿐 아니라 졸업 후 취업경험, 첫 취업 소요기간, 재학 중 직장체험, 취업시험 준비 등에 관한 통계가 포함되어 있다.

- [2025년 경제활동인구조사 청년층 부가조사 결과](https://www.kostat.go.kr/board.es?act=view&bid=210&list_no=437676&mid=a10301010000)

이 데이터는 **YP2021과 직접 합쳐서 학습하지 않고**, 최종 발표에서 YP2021 분석 결과를 해석하고 비교하는 보조자료로 사용한다.

## 1.4 자체 수집 데이터

프로젝트 후반에는 **현재 취업준비 중이거나 최근 취업에 성공한 약 30명**을 대상으로 별도의 설문을 진행할 예정이다.

이 데이터는 모델을 다시 학습시키는 용도가 아니라,

- 실제 취업준비자의 특성을 모델에 입력했을 때 결과가 어떻게 나오는지
- 모델이 중요하다고 판단한 Feature가 실제 경험과 어느 정도 일치하는지
- 실제 사용자에게 모델 결과를 설명할 수 있는지

등을 확인하는 **소규모 외부 검증 및 사례분석 데이터**로 사용한다.

30명은 통계적으로 충분한 외부 Test Dataset이라고 보기 어렵기 때문에, 최종 발표에서도 **대규모 성능 검증이 아니라 파일럿 검증**으로 표현한다.

# 2. 데이터셋 전처리 계획

## 2.1 공통 원칙

Global Model과 Local Model의 차이는 **학습 대상 데이터의 범위**뿐이어야 한다.

따라서 두 모델에서 가능한 한 다음 항목은 동일하게 유지한다.

- 2023년까지 알 수 있는 정보만 Feature로 사용
- 2024년 취업 여부를 Target으로 사용
- 동일한 Feature 목록
- 동일한 결측치 처리 방식
- 동일한 범주형 변수 처리 방식
- 동일한 이상치 처리 기준
- 동일한 모델 및 평가 방식

특히 **2024년에 조사된 현재 직업, 임금, 직종 등의 정보는 취업 결과를 이미 알려주는 정보이므로 Feature에 넣지 않는다.**

---

## 2.2 Global Model 전처리

Global Model의 목적은 **전체 청년에서 공통적으로 나타나는 취업 예측 패턴을 학습하는 것**이다.

### 1단계. 분석 대상자 선정

2024년 4차 조사 응답자 **9,665명**을 기준으로 2023년 3차 조사자료를 연결한다.

즉,

> **2023년 개인 특성 → 2024년 취업 여부**

라는 형태의 데이터셋을 만든다.

단, 9,665명은 정확히는 **4차 조사 응답자 수**이므로, 실제 모델링 단계에서는 3차 자료와 연결 가능한 사람과 필요한 Feature가 존재하는 사람을 다시 확인하여 최종 표본 수를 기록한다.

### 2단계. Feature 구성

우선 검토할 Feature 범주는 다음과 같다.

- 성별, 연령, 지역
- 학력
- 대학 유형 및 전공
- 자격증
- 직업교육·훈련 경험
- 재학 중 일자리 경험
- 과거 일자리 경험
- 취업준비 경험
- 구직활동 경험
- 이전 경제활동상태

최종 Feature 목록은 코드북과 통합설문지를 확인한 뒤 확정한다.

### 3단계. 데이터 정제

다음 항목을 확인한다.

- 실제 결측치
- 해당 문항의 응답 대상이 아니어서 발생한 **비해당 값**
- 무응답
- 비정상적으로 큰 횟수·기간 등의 이상치
- 동일한 의미를 가진 범주의 지나친 세분화
- 범주별 표본 수가 지나치게 작은 변수

특히 YP2021은 설문 분기 때문에 **비해당과 단순 결측을 구분해야 하므로 코드북을 기준으로 처리한다.**

### 최종 형태

```text
2023년 Feature
        ↓
Global Model
        ↓
2024년 취업 / 미취업
```

---

## 2.3 Local Model 전처리

Local Model의 목적은 **희망직군별로 취업 예측에 필요한 정보가 실제로 달라지는지 확인하는 것**이다.

처음에는 2023년 희망직업 정보만 사용하려 했지만 표본이 지나치게 적다는 문제가 있었다.

현재 내부 집계 기준으로,

> 4차 조사 응답자 중<br>
> **2023년 희망직업 정보가 존재하는 사람: 약 917명**

에 불과했다.

따라서 2021~2023년의 실제 희망직업 응답을 모두 다시 조사하였다.

YP2021에는 크게 두 종류의 희망직업 정보가 존재한다.

- **취업·이직을 준비하면서 현재 희망하는 직업**
- **졸업 전후 취업준비 과정에서 응답한 장래 희망직업**

현재 내부 집계 결과, **1~3차 중 한 번이라도 이 두 종류의 실제 희망직업 정보를 가지고 있으며 4차에도 응답한 사람은 중복 제거 후 약 3,921명**이다.

따라서 Local Dataset은 다음과 같이 만든다.

### 1단계. 4차 응답자 기준으로 1~3차 데이터 구성

4차 조사에 응답한 사람을 기준으로

- 1차
- 2차
- 3차

데이터를 개인 ID 기준으로 연결한다.

### 2단계. 실제 희망직업 정보 보유자 추출

1~3차 중 **실제로 희망직업에 응답한 기록이 하나 이상 존재하는 사람**만 추출한다.

현재 예상 규모:

> **약 3,921명**

### 3단계. 중복 응답 정리

한 사람이 여러 차수에서 희망직업에 응답했을 수 있으므로, 한 사람당 하나의 희망직군만 남긴다.

기본 원칙은:

> **가장 최근에 실제로 응답한 희망직업을 우선 사용**

한다.

같은 시점에 여러 종류의 희망직업 정보가 존재한다면 **현재 취업·이직 준비 과정에서 응답한 희망직업을 우선**하고, 졸업 시점의 장래 희망직업은 보완적으로 사용한다.

또한 다음 정보를 별도로 남긴다.

- 희망직업을 응답한 연도
- 어떤 종류의 희망직업 문항에서 가져왔는지

이는 나중에 오래된 희망직업을 사용한 것이 결과에 영향을 미쳤는지 확인하기 위해 필요하다.

### 4단계. Feature 기준시점 통일

여기가 중요하다.

희망직업은 1~3차에서 가져오더라도, **취업예측에 사용하는 Feature는 Global Model과 동일한 기준으로 구성한다.**

즉,

> 희망직군 결정 → 1~3차 실제 응답 활용<br>
> 취업예측 Feature → 2023년 기준<br>
> Target → 2024년 취업 여부

로 맞춘다.

그래야 Global Model과 Local Model을 공정하게 비교할 수 있다.

### 5단계. 동일한 전처리 적용

Global Dataset과 동일하게

- 결측치
- 비해당
- 이상치
- 범주형 변수
- 희소 범주

를 처리한다.

### 6단계. 6개 희망직군으로 분리

최종적으로 약 3,921명의 데이터를 앞에서 정의한 6개 직군으로 나눈다.

```text
희망직업 정보가 있는 4차 응답자
               │
       중복 응답 제거
               │
      최신 실제 응답 선택
               │
        약 3,921명
               │
       KECO → 6개 직군
               │
 ┌─────────────┼─────────────┐
경영·사무   연구·공학   교육·공공 ...
     ↓           ↓           ↓
 Local Model  Local Model  Local Model
```

직군별 최종 인원은 **KECO 6개 그룹 매핑표가 확정된 뒤 다시 산출한다.**

---

# 3. 모델링 계획

Global Model과 6개의 Local Model에는 **동일한 모델링 프로토콜**을 사용한다.

이는 이번 프로젝트에서 매우 중요하다.

예를 들어 Global Model에는 강한 모델을 사용하고 Local Model에는 다른 전처리나 다른 하이퍼파라미터 탐색을 적용하면,

> 성능 차이가 데이터 때문인지<br>
> 모델링 방식 때문인지

구분하기 어려워지기 때문이다.

따라서 다음 조건을 통일한다.

| 항목 | Global / Local 공통 적용 |
|---|---|
| Feature | 동일 |
| Target | 2024년 취업 여부 |
| 결측치 처리 | 동일 |
| 범주형 변수 처리 | 동일 |
| 이상치 처리 | 동일 |
| 데이터 분할 방식 | 동일 원칙 |
| 모델 종류 | 동일 |
| 하이퍼파라미터 탐색 범위 | 동일 |
| 교차검증 | 동일 |
| Random Seed | 동일 |
| 평가 지표 | 동일 |

이를 통해 최종적으로 확인하려는 것은 다음 두 가지다.

### 비교 1. 예측성능

> **전체 청년 데이터로 학습한 Global Model과 직군별 Local Model 중 어느 쪽이 해당 직군 청년의 취업 여부를 더 잘 예측하는가?**

### 비교 2. 주요 Feature

> **희망직군에 따라 취업예측에서 중요하게 사용되는 Feature가 실제로 달라지는가?**

따라서 프로젝트의 전제는

> ❌ 직군마다 중요한 Feature가 다르다.

가 아니라,

> ⭕ **직군마다 중요한 Feature가 다를 것이라는 가설을 세우고 실제 데이터로 검증한다.**

이다.

또한 Feature Importance가 높다고 해서 해당 요소가 **취업을 원인적으로 증가시킨다고 해석하지 않는다.**

---

# 4. 지금까지의 진행 흐름과 앞으로 결정할 내용

## 4.1 지금까지 결정된 흐름

처음에는 **2023년 희망직업 정보만 이용하여 직군별 데이터셋을 만들 계획**이었다.

하지만 데이터를 직접 확인한 결과,

> 전체 4차 응답자 약 **9,665명**<br>
> → 2023년 희망직업 정보 보유자 약 **917명**

으로 표본이 지나치게 감소했다.

6개 직군으로 다시 나누면 각 Local Model의 데이터가 너무 작아질 가능성이 높았다.

따라서 YP2021이 패널 데이터라는 점을 이용해 **2021~2023년의 실제 희망직업 응답을 다시 조사**하였다.

그 결과 현재 내부 집계 기준으로,

> **4차 조사에도 응답했고, 1~3차 중 적어도 한 번 실제 희망직업 정보를 제공한 사람 = 약 3,921명**

으로 표본을 확대할 수 있었다.

따라서 현재 계획은

```text
                     YP2021
                       │
            4차 응답자 기준 표본 구성
                       │
          ┌────────────┴────────────┐
          │                         │
        Global                    Local
          │                         │
   2023년 Feature          1~3차 희망직업 확인
          │                         │
          │                 중복 제거 / 최신값 선택
          │                         │
          │                   6개 직군 분리
          │                         │
          └────────────┬────────────┘
                       │
              동일한 모델링 프로토콜
                       │
                       ▼
               2024 취업 여부 예측
                       │
                       ▼
            Global vs Local 비교
```

로 정리한다.

---

## 4.2 다음 회의에서 결정해야 하는 사항

현재는 **데이터 구성 방식까지 합의한 상태**라고 보면 된다.

다음 단계부터는 팀 전체가 같은 방식으로 작업할 수 있도록 아래 내용을 회의에서 확정해야 한다.

1. **6개 직군의 정확한 KECO 매핑**
   - 어떤 직업을 어느 직군에 포함할지
   - 표본이 지나치게 작은 직군을 합칠지

2. **최종 Feature 목록**
   - 학력
   - 전공
   - 자격증
   - 직업훈련
   - 일경험
   - 구직경험
   - 인구통계 변수 등

3. **결측치·비해당 처리 방법**
   - 삭제
   - 대체
   - 별도 범주 처리 등의 기준

4. **이상치 처리 기준**

5. **사용할 모델**
   - 어떤 모델들을 공통으로 비교할지

6. **하이퍼파라미터 탐색 범위**
   - 팀원마다 임의로 설정하지 않고 공통 범위를 사용

7. **Train / Validation / Test 및 교차검증 방식**

8. **최종 평가 지표**
   - Accuracy
   - Precision
   - Recall
   - F1
   - ROC-AUC
   - Confusion Matrix 등에서 어떤 지표를 주 지표로 사용할지 결정

9. **직군별 최소 표본 수 기준**
   - 직군의 데이터가 너무 작으면 별도 Local Model을 만드는 것이 적절한지 재검토

10. **30명 외부 표본조사 설계**
    - 어떤 질문을 받을지
    - 현재 취업준비자와 취업자의 비율
    - 모델 결과와 무엇을 비교할지

# 5. 프로젝트 진행 순서 요약

최종적으로 팀이 따라갈 순서는 다음과 같다.

**① YP2021 데이터 구조 확인**<br>
→ 유저가이드·코드북·설문지 확인

**② Global Dataset 생성**<br>
→ 4차 응답자 기준<br>
→ 2023년 Feature<br>
→ 2024년 취업 여부 Target

**③ Local Dataset 생성**<br>
→ 4차 응답자 기준<br>
→ 1~3차 실제 희망직업 탐색<br>
→ 중복 제거<br>
→ 최신 실제 희망직업 선택<br>
→ 약 3,921명<br>
→ 6개 직군 분리

**④ 공통 전처리**

**⑤ 동일한 조건으로 Global / Local 모델 학습**

**⑥ 하이퍼파라미터 튜닝**

**⑦ Global vs Local 성능 및 주요 Feature 비교**

**⑧ 약 30명 대상 파일럿 외부 검증**

**⑨ 보조 통계자료와 비교하여 결과 해석**

**⑩ 최종 결론 및 발표**

최종 발표의 핵심은 단순히 **“어떤 모델의 정확도가 가장 높았다”**가 아니라,

> **전체 청년에게 공통적으로 적용되는 취업 예측 모델과 희망직군별 특화 모델을 비교했을 때 실제로 직군을 구분하는 것이 도움이 되었는지, 그리고 직군별로 어떤 취업준비 특성이 다르게 나타났는지**

를 설명하는 것으로 잡는 것이 좋다.
