# 청년패널2021 직군별 취업전환 예측 프로젝트 진행 계획

## 0. 프로젝트 방향

이번 프로젝트의 기본 목표는 **YP2021 1~4차 패널자료를 Person-Period 형태로 구성하여, 기준연도에 미취업 상태인 청년의 차년도 취업전환 여부를 예측하고, 희망직군별 Local Model이 전체 미취업 청년을 학습한 Global Model보다 실제로 더 유용한지 확인하는 것**이다.

이를 위해 두 종류의 모델을 만든다.

- **Global Model**: 희망직군을 구분하지 않고 기준연도 미취업 청년 전체를 대상으로 차년도 취업전환 여부를 예측
- **Local Model**: Global 대상 중 기준연도까지 실제 희망직업 정보가 존재하는 사람을 6개 희망직군으로 나누어 직군별 차년도 취업전환 여부를 예측

두 모델을 동일한 조건에서 비교하여 다음 질문에 답하는 것이 최종 목적이다.

> **희망직군별로 별도의 취업전환 예측 모델을 만드는 것이 전체 미취업 청년을 대상으로 하나의 모델을 만드는 것보다 실제로 더 효과적인가?**

또한 Local Model별 주요 Feature를 비교하여 **희망직군에 따라 취업전환과 관련성이 높은 특성이 다르게 나타나는지** 확인한다.

중요한 점은 **구직활동이나 취업준비 여부를 표본 선정 조건으로 사용하지 않는 것**이다. 현재 구직 중인지, 최근 취업준비를 했는지, 직업훈련·시험준비 등을 했는지는 미취업 청년 내부의 차이를 설명하는 **Feature**로 사용한다.

# 1. 사용할 데이터셋

## 1.1 주 데이터: 청년패널2021

한국고용정보원의 **청년패널2021(YP2021) 1~4차 조사자료**를 프로젝트의 핵심 데이터로 사용한다.

이번 프로젝트에서는 한 사람을 한 번만 사용하는 단면 구조가 아니라, 각 연도의 상태와 다음 연도의 취업전환을 연결한 **Person-Period 구조**로 사용한다.

| Person-Period | Feature 기준시점 | Target 시점 |
|---|---:|---:|
| 2021 → 2022 | 2021년 | 2022년 |
| 2022 → 2023 | 2022년 | 2023년 |
| 2023 → 2024 | 2023년 | 2024년 |

같은 사람이 여러 차수에 응답했다면 서로 다른 기준연도의 Person-Period 행으로 여러 번 포함될 수 있다.

### 분석 대상

각 기준연도에서 다음 조건을 모두 만족하는 사람만 포함한다.

1. 기준연도와 다음연도에 모두 응답
2. 기준연도 `ECOACT ∈ {2, 3}`
   - 실업자
   - 비경제활동인구
3. 다음연도 `ECOACT ∈ {1, 2, 3}`으로 취업전환 Target을 판정할 수 있음

즉 **구직자·취업준비자만 선별하지 않고 기준연도 미취업자 전체를 분석대상으로 사용한다.**

`y**c602`의 구직 여부와 `y**c635`의 최근 취업준비 여부는 표본 포함 조건에서 제외하고, 해당 정보는 모델이 이용할 수 있는 기준연도 Feature로 남긴다.

### 현재 원자료 기준 Global Person-Period 표본

| 전환 | 전체 행 | 다음연도 취업 | 다음연도 미취업 | 취업전환율 |
|---|---:|---:|---:|---:|
| 2021 → 2022 | 6,010 | 1,349 | 4,661 | 22.45% |
| 2022 → 2023 | 4,916 | 1,333 | 3,583 | 27.12% |
| 2023 → 2024 | 3,980 | 1,214 | 2,766 | 30.50% |
| **합계** | **14,906** | **3,896** | **11,010** | **26.14%** |

고유 개인은 **7,143명**이다.

### Target

Target은 `employment_transition`으로 정의한다.

- 다음연도 `ECOACT = 1` → **1: 취업전환**
- 다음연도 `ECOACT ∈ {2, 3}` → **0: 미취업 유지**

희망직군과 실제 취업직군의 일치 여부는 현재 Target에 포함하지 않는다.

프로젝트 후반에는 현재 취업준비 중이거나 최근 취업에 성공한 약 30명을 대상으로 별도의 설문을 진행할 예정이다.

30명은 통계적으로 충분한 외부 Test Dataset으로 보지 않고 파일럿 검증으로 표현한다.

# 2. 데이터셋 전처리 계획

## 2.1 공통 원칙

Global Model과 Local Model의 차이는 **학습 대상 데이터의 범위**뿐이어야 한다.

따라서 다음 항목은 동일하게 유지한다.

- 동일한 Person-Period 구조
- 동일한 Target
- 동일한 Feature 목록
- 동일한 결측치·비해당 처리
- 동일한 범주형 변수 처리
- 동일한 이상치 처리 기준
- 동일한 Train/Test 분할 원칙
- 동일한 모델 후보
- 동일한 하이퍼파라미터 탐색 원칙
- 동일한 평가 방식

모든 Feature는 **각 Person-Period의 baseline year까지 실제로 알 수 있었던 정보만** 사용한다.

다음연도 임금, 직종, 근로형태, 자격증, 훈련, 구직활동 등은 미래정보이므로 Feature에 넣지 않는다.

### 인구통계
- 성별
- 연령
- 5권역 지역
- 기준연도

### 교육

- 기준연도 미취업 상태 유형: 실업 / 비경제활동
- 최근 구직경험
- 최근 취업준비 경험
- 취업준비 활동 유형
- 졸업 전후 취업준비·구직 경험

### 자격증
- 자격증 보유 여부
- 누적 자격증 수
- 취업 목적 자격증 여부
- 전공 관련 자격증 여부

### 직업훈련
- 직업훈련 경험 여부
- 누적 훈련 횟수
- 누적 훈련시간

### 시험준비
- 시험준비 경험
- 시험준비 횟수
- 현재 시험준비 여부

### 일경험
- 재학 중 일경험
- 기준연도 이전 근로경험 여부
- 과거 일자리 수
- 누적 근로개월

상태형 변수는 baseline year의 현재 값을 사용하고, 이력형 변수는 baseline year까지 관측된 이력만 누적한다.

**구직·취업준비·훈련 여부는 이제 분석대상을 거르는 조건이 아니라, 전체 미취업자 중 누가 다음연도에 취업하는지 설명하기 위한 Feature이다.**

---

## 2.3 결측·비해당·설문분기 처리

YP2021은 설문 분기가 많기 때문에 단순 결측과 비해당을 구분한다.

- 실제 결측 수치형 → Train median
- 실제 결측 범주형 → `Missing`
- 논리적으로 0이 맞는 경우 → 0
- 문항 비해당인데 0으로 볼 수 없는 경우 → `NotApplicable`
- 무응답·모름·응답거절 특수코드 → 변수별 코드북 기준으로 `NaN`

특수결측을 하나의 숫자 범위로 일괄 처리하지 않고, `code/config/yp2021_missing_rules.json`의 변수별 규칙을 사용한다.

특히 비경제활동인구 등 설문분기로 인해 특정 구직·취업준비 문항을 받지 않은 경우를 단순히 `0=경험 없음`으로 바꾸지 않는다.

## 2.5 Local Dataset 생성

Local Dataset은 **Global Person-Period의 부분집합**이다.

Global 대상 중 각 baseline year까지 실제 희망직업 정보가 존재하는 행만 Local 후보가 된다.

### 희망직업 선택 규칙

- 2021→2022: 2021년까지의 희망직업만 사용
- 2022→2023: 2022년까지의 희망직업 사용
- 2023→2024: 2023년까지의 희망직업 사용

여러 시점에 응답한 경우 **baseline year까지 가장 최근의 실제 희망직업**을 선택한다.

같은 시점에 두 종류의 희망직업이 있으면:

1. 현재 취업·이직 준비 과정의 희망직업
2. 졸업 전후 장래 희망직업

순으로 우선한다.

희망직업은 **Local 직군 소속을 정하는 용도**로만 사용하고 모델 Feature에는 넣지 않는다.

# 3. Train/Test 분할 및 모델링 계획

## 3.1 데이터 분할

같은 사람이 여러 Person-Period 행을 가질 수 있으므로 행 단위 Random Split을 사용하지 않는다.

`SAMPID`를 그룹으로 사용하여:

- Train 80%
- Test 20%
- `StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42)`
- outer fold 0을 고정 Test로 사용

한다.

Global Dataset에서 `split_ids.csv`를 한 번 생성하고 Local도 같은 SAMPID 소속을 그대로 사용한다.

**분석대상 변경으로 Global 모집단이 달라져 기존 3,278행 기준 `split_ids.csv`는 새 Global Dataset 기준으로 재생성하였다.**

---

## 3.2 모델 후보

Global 및 모든 Local Model에서 아래 5개 모델을 동일하게 사용한다.

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. XGBoost
5. LightGBM

---

## 3.3 전처리 및 인코딩

- 범주형 → One-Hot Encoding
- Train 빈도 10 미만 범주 → `Other`
- `Missing`, `NotApplicable`은 별도 유지
- Logistic Regression만 StandardScaler
- Decision Tree / Random Forest / XGBoost / LightGBM은 스케일링하지 않음
- 일반적인 IQR / z-score 기준의 행 삭제는 사용하지 않음

모든 학습형 전처리는 Train에서만 fit한다.

---

## 3.4 하이퍼파라미터 튜닝

기본적으로 `GridSearchCV`를 사용한다.

계산량이 과도한 경우 Random Forest, XGBoost, LightGBM은 팀 공통으로 `RandomizedSearchCV(n_iter=30, random_state=42)`로 변경할 수 있다.

탐색 기준은 **F1**로 통일하며 팀원마다 임의로 탐색 방식이나 후보 범위를 바꾸지 않는다.

---

## 3.5 평가 지표

### 주 지표
- F1

### 보조 지표
- Accuracy
- Precision
- Recall
- ROC-AUC
- Confusion Matrix

Positive class는 `employment_transition = 1`이고 threshold는 0.5로 고정한다.

---

## 3.6 Feature Importance

공통 비교 방법으로 **Permutation Importance**를 사용한다.

- 최종 Test Dataset에서 계산
- scoring = F1
- n_repeats = 20
- random_state = 42
- One-Hot 이전 원 Feature 단위로 비교

Logistic coefficient와 Tree 기반 built-in importance는 보조자료로만 사용한다.

# 4. Global vs Local 비교

각 희망직군에서 **동일한 Local Test Sample**을 Global Model과 Local Model 모두에 입력한다.

```text
해당 직군 Local Test Sample
       │
       ├─ 전체 미취업자에게 학습된 Global Model
       │
       └─ 해당 희망직군에 학습된 Local Model
```

핵심 비교값:

> **ΔF1 = Local F1 - Global F1**

보조로 Accuracy, Precision, Recall, ROC-AUC 차이도 기록한다.

불확실성은 SAMPID 단위 bootstrap 1,000회 95% CI를 계산한다.

## 4.1 Local Model 최소 표본 기준

정식 비교:

- Person-Period 150 이상
- 고유 SAMPID 100 이상
- Positive 40 이상
- Negative 40 이상

탐색적 비교:

- Person-Period 100~149
- Positive/Negative 각각 30 이상

그보다 작은 직군은 정식 Local 비교에서 제외한다.

# 9. 프로젝트 해석 원칙

최종 발표의 핵심은 단순히 **“어떤 모델의 정확도가 가장 높았다”**가 아니다.

최종적으로 설명하려는 것은 다음 두 가지다.

> **전체 미취업 청년에게 공통적으로 적용되는 취업전환 예측 모델과 희망직군별 특화 모델을 비교했을 때 실제로 직군을 구분하는 것이 도움이 되었는가?**

그리고

> **미취업 청년의 구직·취업준비·교육·훈련·자격증·일경험 등의 특성 중 어떤 요소가 취업전환 예측에 중요하게 사용되며, 그 패턴이 희망직군에 따라 달라지는가?**

Feature Importance는 예측모델의 설명을 위한 것이며, 중요도가 높다고 해서 해당 Feature가 취업을 원인적으로 증가시킨다고 해석하지 않는다.
