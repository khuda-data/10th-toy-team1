## 2026-08-09 (4) — ⭐ 대원칙 신설: 판단은 사람이 쓴다 + 작성 출처 자동 기록

### 정한 것 (팀 최상위 규칙)
- **`AGENTS.md` 맨 위에 「⭐ 대원칙」 신설** — 모든 규칙에 우선한다.
  - 코드·서식·변환 등 세세한 작업은 AI에게 맡기고 사람이 과하게 개입하지 않는다.
  - 그러나 **논문 인용 이유 · 문항 선택 · 설문 대상자 설계 · 방법론 설계 · 결과 해석 · 문제 정의**는 **사람이 전면 개입해 모든 내용을 작성**한다. AI에게 예시를 제안받을 수는 있으나 **근거·해석·시선은 사람이 쓴다.**
- **「⭐-2 작성 출처 기록」 신설** — 시키지 않아도 AI가 자동 수행:
  ① 모든 문서 하단에 「🖊 작성 출처」 블록 (구간별 작성 주체 + `⬜ 미검토`/`✅ 검토완료`)
  ② 판단·해석 대목에 인라인 표시 `〔AI 제안 · 사람 검토 필요〕` / `〔사람 확정 · 아이디 날짜〕`
  ③ **AI가 스스로 `⬜`를 `✅`로 승격시키지 않는다**
  ④ 세션 로그에 사람 판단 / AI 초안 구분 기록
  ⑤ 미검토 항목이 남은 채 커밋하면 사용자에게 알린다
  ⑥ 사람의 판단 근거는 **발언 원문 그대로** 남긴다

### 연동 반영 (§10 연동 체크)
- `AGENTS.md` 빠른 라우팅 표에 대원칙 행 추가 · 서두의 옛 주제("서울 안전 경로 추천") → 현재 주제로 수정
- 루트 `README.md` 규칙 요약 · `온보딩.md` §4(5가지→6가지) · `AI활용팁.md` §5에 각각 반영
- 오늘 만든 문서 6개(07·08·09·회의기록 2·검색기록)에 「🖊 작성 출처」 블록 소급 적용
