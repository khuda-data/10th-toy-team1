### 정한 것
- **PDF는 레포에 커밋하지 않는다. 모든 PDF 내용은 md 변환본으로 커밋** (사용자 결정). 기존 커밋된 PDF 3개는 유지, 논문 원본 PDF는 계속 커밋(출처 자료 예외).
- **AI 작업 규칙의 단일 소스 = 루트 `AGENTS.md`.** CLAUDE.md/GEMINI.md에는 규칙을 적지 않는다.
- **시각 산출물(앱·PPT·대시보드 등)의 디자인 소스 = `DESIGN-apple.md`** (사용자 결정). 해설 HTML만 `DESIGN-notion.md` 유지.
- **코드는 브랜치 + PR(리뷰 1명 이상), 문서 md는 main 직푸시.** 모듈 폴더마다 주인 1명, 개인 실험은 `sandbox/<영문이름>/`, 코드 경로는 ASCII.
- **AI 세션은 `작업기록/<영문이름>/YYYYMMDD-<주제>.md`로 기록**해 같은 커밋/PR에 포함. plan = 결정된 것(현재형), 작업기록 = 일어난 일(시간순 이력)로 역할 분리 — "plan에 지시사항을 쌓는" 기존 습관을 대체 (폴더명은 사용자 확정).
- **레포 루트 = 1조 프로젝트 그 자체** (래퍼 폴더 금지). **루트 README.md = 파일 지도** — 새 폴더·중요 산출물은 만든 커밋에서 지도에 등록(AI 자동 수행 규칙). 폴더 한정 지침은 루트 AGENTS.md에 쌓지 않고 해당 폴더의 AGENTS.md로 분산.
- **세션 기록의 책임은 사람이 아니라 AI** (사용자 지시). 훅이 기계적으로 뒷받침.
- **개인 산출물과 팀 산출물의 분리** (사용자 지시): 개인 중간 결과물은 자기 `sandbox/<영문이름>/`, `data/result/`에는 통합 코드가 만든 공용·최종 결과물만. 승격 흐름: sandbox 실험 → 검증 → `code/` PR → 그 코드의 산출물이 `data/result/`.
- **협업 통합 4단계를 웹·분석 공통 표준으로** (사용자 지시 "모든 협업 과정에서 문제없도록"): ① 돌아가는 뼈대를 main에 먼저 ② 모듈 간 약속을 06-인터페이스에 기록(변경은 PR+공유로만) ③ 각자 폴더+브랜치 ④ 작은 PR 자주+통합 확인 담당(기본 팀장).
