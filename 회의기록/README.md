# 회의기록 — 안건함과 회의록

**무엇**: 팀 회의와 관련된 두 가지가 들어간다.

| 파일 | 무엇 |
|---|---|
| `안건.md` | **다음 회의에서 다룰 것들.** 작업하다 막힌 문제, 팀이 정해야 할 사안이 생기면 즉시 한 줄 추가 (누구나, 언제든) |
| `YYYYMMDD-<주제>.md` | 회의 1번 = 파일 1개. 아래 템플릿으로 기록 |

**왜 만들었나**: 막힌 문제와 논의거리는 생기는 순간 적어두지 않으면 회의 때 기억나지 않고, 회의에서 정한 것은 기록하지 않으면 2주 뒤 "그때 뭐라고 정했더라"로 같은 논의를 반복하게 된다. 안건은 쌓이는 즉시, 결정은 회의 직후 남긴다.

**규칙**:
- 회의에서 **결정된 것은 여기 두는 걸로 끝이 아니다** — `plan/`(결정의 현재 상태)에도 반영한다. 회의기록 = 그날의 이력, plan = 지금의 진실.
- 회의가 끝나면 다룬 안건을 `안건.md`에서 지우고 회의록으로 옮긴다.
- 액션 아이템에는 반드시 **누가 · 무엇을 · 언제까지**를 적는다.

## 회의록 템플릿 (복사해서 시작)

```markdown
# YYYY-MM-DD 회의 — <주제 한 줄>

- 참석:
- 안건: (안건.md에서 가져온 것들)

## 논의 내용
- (안건별로 어떤 얘기가 오갔는지 요지)

## 결정된 것
- (결정 + 근거 한 줄. plan/ 반영 여부 표시)

## 액션 아이템
| 누가 | 무엇을 | 언제까지 |
|---|---|---|

## 다음 회의로 넘긴 것
- (결론 못 낸 안건 → 안건.md에 남겨두기)
```
