지금까지의 세션을 AGENTS.md 규칙대로 마무리해줘:

1. 오늘 세션의 작업기록(`작업기록/<git아이디>/YYYYMMDD-<주제>.md`)을 최신 상태로 정리해줘 — 지침·AI가 한 일·검증·남은 것 (§9).
2. 이번 세션에서 지침 문서를 고쳤다면, §10 연동 체크(관련 문서 grep → 같은 커밋에서 수정)를 했는지 확인하고 빠진 곳이 있으면 지금 고쳐줘.
3. 새로 만든 폴더·중요 산출물이 루트 README.md 파일 지도에 등록됐는지 확인해줘 (§10).
4. 남이 알아야 할 변경이면 루트 `업데이트.md` 맨 위에 항목을 추가해줘 — 무엇이 바뀌었나 / 팀원이 할 일 / 자세히 (§13).
5. `git diff` 요약을 쉬운 말로 보여주고, 내가 승인하면 커밋 메시지를 제안해서 커밋 → 푸쉬해줘.
6. 해결 못 한 문제나 팀이 정해야 할 사안이 있으면 `회의기록/안건.md`에 추가해줘 (§2-7).
