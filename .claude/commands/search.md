다음을 검색해줘: $ARGUMENTS

`검색기록/README.md`의 규칙과 템플릿을 따라 진행해줘:

1. **사전 확인**: `검색기록/`의 기존 기록을 먼저 확인해 중복을 피하고 (논문이면 `plan/details/03-논문인덱스.md`도), 확인 결과를 기록에 남겨줘.
2. **검색**: 웹 검색으로 후보를 모으되, 검색처와 검색어를 입력한 그대로 기록해줘.
3. **판정**: 후보마다 이름·출처·링크·한줄평과 판정(채택/보류/제외)+이유를 표로 정리해줘. 판정 기준은 우리 프로젝트 목적(`plan/details/01-overview.md`, `04-구현계획`) 기준으로.
4. **저장**: 전 과정을 `검색기록/YYYYMMDD-<git아이디>-<주제>.md`로 저장해줘.
5. **후속 연계**: 채택한 것은 유형별로 이어줘 — 논문은 `논문/<코드명>/` 컨벤션(+필요시 haeseol 절차), 데이터셋은 `data/raw/`+출처 표, 팀 결정이 필요하면 `회의기록/안건.md`.
