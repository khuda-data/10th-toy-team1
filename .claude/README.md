# .claude — Claude Code 팀 설정

**무엇**: `commands/` 안의 md 파일 1개 = 팀 공용 슬래시 명령 1개 (`/wrap`, `/agenda`, `/haeseol`). Claude Code가 이 폴더를 자동 인식한다.

**왜 만들었나**: 자주 시키는 작업(세션 마무리, 안건 추가, 논문 해설)을 매번 길게 설명하지 않고 명령 한 번으로 실행하게 하려고. 레포에 커밋돼 있어서 clone만 하면 팀 전체가 같은 명령을 쓴다.

**규칙**: 새 명령을 만들면 `AI활용팁.md` §3 표에도 한 줄 추가할 것 (연동 체크 §10). 참고: 이 README를 `commands/` 안에 두면 `/README`라는 명령이 돼버려서 한 단계 위인 여기에 둔다. Gemini/Codex 사용자는 명령 파일 내용을 복사해 붙여넣으면 같은 효과.
